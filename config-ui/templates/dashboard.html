About these numbers

Foundry's CPU/memory come live from docker stats. "Requests Served" is nginx's own stub_status counter, totaled across both the public Foundry traffic and this admin site since nginx last restarted. The charts above are built from nginx's own request log instead (method and volume over time), kept only for the trailing 4 hours - older entries are discarded, never written anywhere permanent. See Architecture for how all of this is gathered. Nothing here is simulated - this page re-fetches them in the background.
